# 🎵 Spotify Clone

A responsive, lightweight frontend Spotify clone built using pure web technologies to replicate the core user interface and music streaming experience of the desktop application.

---

## 🚀 Features

* **Authentic UI Layout:** Replicates Spotify's iconic three-column layout, featuring the sidebar navigation, main content discovery panel, and the sticky bottom media player bar.
* **Responsive Design:** Fluid layouts and clean positioning rules that adapt seamlessly across varied monitor sizes and viewports.
* **Interactive Media Controls:** Native JavaScript implementations to handle basic music player states, track browsing, and hover-triggered micro-interactions.
* **Modern Styling System:** Crafted using advanced CSS styling principles, clean font pairing configurations, and smooth hover transition states.

---

## 🛠️ Tech Stack

* **Structure:** HTML5
* **Styling:** CSS3 (Flexbox, Grid layout systems, Custom Scrollbars)
* **Behavior:** JavaScript (ES6+ Client-side logic)
